🐶 Hundpsionatet tassen 🐶
Om projekt
Tassen är en webbplats för ett hunddagis och hundpensionat. 
Syfte.
Att skapa en tydlig webbplats där besökare kan läsa och se till tjänster och skicka en bokning för sin hund.
Projektet är byggt med:
1. HTML ⇥ webbplatsens struktur ⇥ formulär ⇥ label ⇥ input
2. CSS ⇥ design, layout och Responsivitet ⇥ css flexbok och css Grid
3. JavaScript ⇥ interaktivitet och functioner. ⇥ DOM minipulation ⇥ LocalStorage

🐶Webbplats funktioner.
1. öppettider och aktuell tid med hjälp av JavaScript för att visa information om öppettider och uppdatera klockan.

2. Tjänster skriver i en Array med objekt och visar dynamiskt på webbsida.

3. Boknings förfrågningar för besökaren kan fylla i ett formulär med hunds namn, önskat datum och ägarens mobilnummer. Med hjälp av JavaScript att skapa ett boknings objekt. Bokningarna sparar i LocalStorage vilken gör att bokningarna stannar kvar efter laddas om i samma webbläsare. Besökare kan boka och avboka sin bokning. 

4. kund omdömen som lagrar i en Array med objekt och varje objekt som finns ett omdöme och information om vem som har skrivit det.

5. kontakt formulär skriver på HTML men JavaScript kontrollerar formulär och visa återkoppling till besökare. Besökare fyller i sina kontaktuppgifter och ett meddelande.

CSS: Flexbox och Grid
Jag använder både Flexbok och Grid för att skapa en tydlig och respons layout.
CSS Grid där innehållet behöver organiserar i rader och kolumner och det ska passa med tjänster som visar bredvid varandra men jag använder Grid för att passar bra id mobil skärmen.
